# Library Acceptance

Before declaring a library ready, confirm:

- Token collections/modes match agreed source taxonomy and component visual properties bind existing variables.
- Text/effect styles exist when source tokens require them.
- Components have deterministic names, auto layout, usable variants, and meaningful properties.
- Icons/media reuse nested instances or instance swaps.
- Catalogue samples are instances, while legacy names reference canonical families.
- Representative components pass visual, structural, binding, contrast, and touch-target checks.
- A ledger and, when supported, extracted/contract artifacts enable safe continuation.
