# Verification Checklist

Check the authorized scope for:

1. Page and section boundaries: no unrelated changes.
2. Variable integrity: expected collections/modes and visual bindings where tokens exist.
3. Component integrity: useful variants/properties and instance-based examples.
4. Visual integrity: no overlap, clipping, unlaid-out variants, or unexplained duplicates.
5. Accessibility: contrast, legibility, touch targets, and focus order where applicable.
6. Contract integrity: extracted or snapshot/check evidence, with deliberate deviations documented.
